# Support

Need help building on Quantova? Here is where to look.

## Ask the community

The developer forum is the fastest place to get an answer. Browse the Q and A category for common questions such as how to install the SDK, how addresses work, and how to connect to a node. If your question is not there, open a new one.

## Documentation and specifications

The specifications and improvement proposals live in the Quantova organization repositories. Developer content and reference material are published alongside the code. The website at quantova.org links the main resources.

## SDKs

Install the JavaScript SDK from npm as @quantovainc/qcore. The Rust and Python SDKs are QCore.rs and QCore.py. All three wrap the same gateway, where each call is an HTTP POST to /v1/<method>.

## Reporting bugs

Open an issue on the repository that the problem belongs to. For anything security related, follow SECURITY.md instead of filing a public issue.

## Honest status

Quantova is a test network at the pre audit stage. Use the testnet asset TQTOV, which has no real value, and expect interfaces to keep improving on the way to mainnet.
